# Шкільна бібліотека

PHP обслуговує сторінки й API; Vue та Tailwind збираються через Vite у `public/build`.
Підключення до бази й ключ адміністратора задаються у кореневому `.env` або змінними середовища
процесу (значення процесу мають пріоритет). Скопіюйте `.env.example` у `.env` і задайте власний
довгий `ADMIN_API_KEY`; `.env` не має потрапляти в репозиторій.

## Вимоги

- PHP 8.1+ із увімкненим PDO MySQL
- Node.js 18+
- MySQL або MariaDB

## Встановлення та збірка

```powershell
npm install
npm run build
```

Для автоматичної повторної збірки після змін фронтенду запустіть `npm run dev` в окремому терміналі.

Створіть базу `years_lib` у MySQL, налаштуйте `.env` і запустіть PHP.

Відкрийте `http://127.0.0.1:8000`. Каркас API має маршрути `/api/health` та
`/api/health/database`; другий перевіряє підключення до налаштованої бази.

## API книг

- `GET /api/books?category=textbook` повертає підручники; необов'язковий `&grade=9` фільтрує за класом.
- `GET /api/books?category=literature` повертає літературу.
- `GET /api/books/{id}` повертає одну книгу.
- `POST /api/books` створює запис після входу адміністратора.
- `PUT /api/books/{id}` повністю оновлює запис після входу адміністратора.
- `POST /api/admin/login`, `GET /api/admin/session`, `POST /api/admin/logout` керують адмін-сесією.
- `POST /api/admin/covers` приймає перевірену WebP-обкладинку для поточної адмін-сесії.
- `GET /api/admin/books/{id}/loans` повертає статистику та історію видач книги.
- `POST /api/admin/books/{id}/loans` реєструє видачу одного чи кількох примірників; `PUT /api/admin/loans/{id}` редагує її.
- `POST /api/admin/loans/{id}/return` реєструє повне або часткове повернення. Історія видач не видаляється.

Для `POST` і `PUT` передавайте обов'язкові `title` і `category` (`textbook` або `literature`),
а за потреби `author`, `grade`, `pdf_url`, `cover_path` і `total_copies`. Інші поля можуть бути відсутніми або
порожніми. Перед створенням і редагуванням увійдіть через `/admin`; ключ перевіряється сервером,
а авторизація зберігається в HttpOnly SameSite-сесії. `pdf_url`, якщо задано, має бути валідним
HTTPS-посиланням на зовнішній PDF. Сам документ на сайт не завантажується. Схему створює SQL-файл
`db_migrations.sql`, який містить усі міграції послідовно. Виконайте його цілком у phpMyAdmin або
MySQL-клієнті. Подальші міграції додаються в кінець цього файлу з наступним номером.

Зображення обкладинки конвертується браузером у WebP перед завантаженням; сервер перевіряє MIME,
розмір і формат та зберігає його в `public/assets/covers`.
