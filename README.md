# Шкільна бібліотека

PHP обслуговує сторінки й API; Vue та Tailwind збираються через Vite у `public/build`.
Підключення до бази й ключ адміністратора задаються у кореневому `.env` або змінними середовища
процесу (значення процесу мають пріоритет). Скопіюйте `.env.example` у `.env` і задайте власний
довгий `ADMIN_API_KEY`; `.env` не має потрапляти в репозиторій.

## Вимоги

- PHP 8.1+ із увімкненим PDO MySQL
- Node.js 18+
- MySQL або MariaDB

## Встановлення та збірка

```powershell
npm install
npm run build
```

Для автоматичної повторної збірки після змін фронтенду запустіть `npm run dev` в окремому терміналі.

Створіть базу `years_lib` у MySQL, налаштуйте `.env` і запустіть PHP.

Відкрийте `http://127.0.0.1:8000`. Каркас API має маршрути `/api/health` та
`/api/health/database`; другий перевіряє підключення до налаштованої бази.

## API книг

- `GET /api/books?category=textbook` повертає підручники; необов'язковий `&grade=9` фільтрує за класом.
- `GET /api/books?category=literature` повертає всю доступну літературу у випадковому порядку.
- `GET /api/books/{id}` повертає одну книгу.
- `POST /api/books` створює запис після входу адміністратора.
- `PUT /api/books/{id}` повністю оновлює запис після входу адміністратора.
- `DELETE /api/books/{id}` видаляє книгу разом з усією історією її видач після входу адміністратора.
- `POST /api/admin/login`, `GET /api/admin/session`, `POST /api/admin/logout` керують адмін-сесією.
- `POST /api/admin/covers` приймає перевірену WebP-обкладинку для поточної адмін-сесії.
- `POST /api/admin/pdfs` приймає перевірений PDF розміром до 35 МБ для поточної адмін-сесії.
- `GET/POST/PUT/DELETE /api/admin/placements` керують довідником розміщень літератури (для зміни й видалення в URL додається `{id}`).
- `GET /api/admin/books/{id}/loans` повертає статистику та історію видач книги.
- `GET /api/admin/loans/unreturned` повертає всі активні видачі літератури й підручників.
- `POST /api/admin/books/{id}/loans` реєструє видачу одного чи кількох примірників із необов'язковим полем `notes`; `PUT /api/admin/loans/{id}` редагує її.
- `POST /api/admin/loans/{id}/return` реєструє повне або часткове повернення, не видаляючи сам запис.
- `DELETE /api/admin/loans/{id}` видаляє окремий запис з історії видач.

Книги із загальною кількістю примірників `0` приховані від публічних запитів, але залишаються доступними адміністратору.

Для `POST` і `PUT` передавайте обов'язкові `title` і `category` (`textbook` або `literature`),
а за потреби `author`, `grade`, `placement_id`, `is_used`, `pdf_url`, `cover_path` і `total_copies`. Булеве поле
`is_used` визначає, чи використовується підручник (типово `true`). `placement_id` застосовується
до літератури; якщо його не передано, використовується «Загальне». Інші поля можуть бути відсутніми або
порожніми. Перед створенням і редагуванням увійдіть через `/admin`; ключ перевіряється сервером,
а авторизація зберігається в HttpOnly SameSite-сесії. `pdf_url`, якщо задано, має бути валідним
HTTPS-посиланням або шляхом до PDF, завантаженого через адмін-панель. Схему створює SQL-файл
`migrations/db_migrations.sql`, який містить усі міграції послідовно. Виконайте його цілком у phpMyAdmin або
MySQL-клієнті. Подальші міграції додаються в кінець цього файлу з наступним номером.

Зображення обкладинки конвертується браузером у WebP перед завантаженням; сервер перевіряє MIME,
розмір і формат та зберігає його в `public/assets/covers`.
PDF-файли перевіряються за MIME, сигнатурою та розміром і зберігаються в `public/assets/pdfs`.
Ім'я файлу формується з транслітерованої назви книги та короткого випадкового суфікса, наприклад
`ukrainska-mova-5-klas-a1b2c3.pdf`. Для підручника з указаним класом клас також додається перед суфіксом.
Після успішного збереження зміненого PDF-посилання попередній локальний файл видаляється, якщо його не
використовує інша книга.
