# Шкільна бібліотека

PHP обслуговує сторінки й API; Vue та Tailwind збираються через Vite у `public/build`.
Підключення до бази налаштовується змінними середовища процесу. `.env.example` — це лише
шаблон значень: застосунок не читає `.env` автоматично.

## Вимоги

- PHP 8.1+ із увімкненим PDO MySQL
- Node.js 18+
- MySQL або MariaDB

## Встановлення та збірка

```powershell
npm install
npm run build
```

Для автоматичної повторної збірки після змін фронтенду запустіть `npm run dev` в окремому терміналі.

Створіть базу `years_lib` у MySQL і задайте змінні середовища перед запуском PHP.

Відкрийте `http://127.0.0.1:8000`. Каркас API має маршрути `/api/health` та
`/api/health/database`; другий перевіряє підключення до налаштованої бази.

## API книг

- `GET /api/books?category=textbook` повертає підручники; необов'язковий `&grade=9` фільтрує за класом.
- `GET /api/books?category=literature` повертає літературу.
- `GET /api/books/{id}` повертає одну книгу.
- `POST /api/books` створює запис.
- `PUT /api/books/{id}` повністю оновлює запис.

Для `POST` і `PUT` передавайте обов'язкові `title` і `category` (`textbook` або `literature`),
а за потреби `author`, `grade`, `pdf_url` і `cover_path`. Інші поля можуть бути відсутніми або
порожніми. Зміни вимагають заголовок
`X-Admin-Key` зі значенням `ADMIN_API_KEY`. `pdf_url`, якщо задано, має бути валідним
HTTPS-посиланням на зовнішній PDF. Сам документ на сайт не завантажується. Схему створює SQL-файл
`db_migrations.sql`, який містить усі міграції послідовно. Виконайте його цілком у phpMyAdmin або
MySQL-клієнті. Подальші міграції додаються в кінець цього файлу з наступним номером.
